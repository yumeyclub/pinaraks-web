## 🚀 Projeyi GitHub'a Yükleme ve Canlıya Alma (Hosting) Rehberi

Bu proje saf web teknolojileri (HTML5, Vanilla CSS, Modern JavaScript) ile geliştirildiği için hiçbir sunucu kurulumu gerektirmeden **ücretsiz** ve **anında** canlıya alınabilir.

### 1. Adım: GitHub Deposu Açın ve Projeyi Gönderin

1. [GitHub.com](https://github.com) adresine giriş yapın.
2. Sağ üstteki **+** ikonuna tıklayıp **New repository** (Yeni Depo) seçin.
3. Depo adı olarak örneğin `pinaraks-web` yazın. Depoyu **Public** seçin (README ekleme kutucuğunu işaretlemeyin).
4. **Create repository** butonuna basın.
5. Bilgisayarınızda bu proje klasöründe terminal / powershell açıp aşağıdaki komutları çalıştırın (kendi kullanıcı adınız ve repo adınızla):

```bash
git remote add origin https://github.com/<KULLANICI_ADINIZ>/<DEPO_ADINIZ>.git
git branch -M main
git push -u origin main
```

---

### 2. Adım: GitHub Pages ile 10 Saniyede Canlıya Alma (Ücretsiz)

1. GitHub'daki deponuzun sayfasına gidin.
2. Üst menüden **Settings** (Ayarlar) sekmesine tıklayın.
3. Sol menüden **Pages** seçeneğine tıklayın.
4. **Branch** kısmında `None` yerine `main` seçin ve klasör olarak `/ (root)` seçip **Save** butonuna tıklayın.
5. 1-2 dakika içinde siteniz dünya çapında ücretsiz olarak canlıya alınacaktır!
   - Canlı linkiniz şu formatta olacaktır: `https://<kullanici-adiniz>.github.io/<depo-adiniz>/`

---

### Alternatif Ücretsiz Canlıya Alma Seçenekleri

- **Netlify:** [netlify.com](https://www.netlify.com) -> GitHub deponuzu bağlayıp tek tıkla canlıya alabilir veya klasörü doğrudan sürükleyip bırakabilirsiniz.
- **Vercel:** [vercel.com](https://vercel.com) -> GitHub deponuzu seçip `Deploy` butonuna basmanız yeterlidir.
- **Özel Alan Adı (Custom Domain):** `pinaraks.com` alan adınızı GitHub Pages veya Netlify ayarlarına girerek kolayca sitenize bağlayabilirsiniz.
